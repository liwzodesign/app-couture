# Kakatargraphic - Gestion de Services Graphiques

Une application web moderne pour la gestion de services graphiques, développée avec React, TypeScript, et Tailwind CSS.

## 🚀 Fonctionnalités

- 📊 Tableau de bord interactif
- 👥 Gestion des clients
- 📦 Gestion de l'inventaire
- 🎨 Gestion des services graphiques

## 🛠️ Technologies Utilisées

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Zustand (Gestion d'état)
- React Router
- Vitest (Tests)

## 📋 Prérequis

- Node.js (version 18 ou supérieure)
- npm ou yarn

## 🚀 Installation

1. Clonez le repository :
```bash
git clone [URL_DU_REPO]
cd kakatargraphic
```

2. Installez les dépendances :
```bash
npm install
# ou
yarn install
```

3. Lancez le serveur de développement :
```bash
npm run dev
# ou
yarn dev
```

L'application sera accessible à l'adresse `http://localhost:5173`

## 🧪 Tests

Pour lancer les tests :
```bash
npm run test
# ou
yarn test
```

## 📦 Build

Pour créer une version de production :
```bash
npm run build
# ou
yarn build
```

## 📁 Structure du Projet

```
src/
├── components/     # Composants React réutilisables
├── pages/         # Pages de l'application
├── data/          # Données mockées et services
├── utils/         # Utilitaires
├── types/         # Types TypeScript
└── store/         # État global (Zustand)
```
